Política de privacidad — GTA Publicador

Última actualización: 21 de noviembre de 2026.

GTA Publicador es una herramienta interna que usa el equipo de contenido de GTA 6 para subir sus propios videos a sus propias cuentas.

Qué datos usamos

  • Las autorizaciones (tokens) que el propio equipo otorga a sus cuentas de YouTube, Instagram, Facebook, TikTok y X, solo para subir y publicar videos.
  • El nombre y el identificador del canal o cuenta, para confirmar dónde se publica.

Qué no hacemos

  • No accedemos a cuentas de terceros ni recopilamos datos de otros usuarios.
  • No vendemos, compartimos ni cedemos ningún dato.
  • No usamos los datos para publicidad.

Almacenamiento y eliminación

Las autorizaciones se guardan cifradas como secretos del sistema de publicación y se pueden revocar en cualquier momento desde la configuración de seguridad de cada cuenta (por ejemplo, myaccount.google.com/permissions).

El uso de datos de las API de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. GTA Publicador usa los servicios de API de YouTube; ver también las Condiciones del servicio de YouTube y la Política de privacidad de Google.
